# Changelog

## 1.0.5 - first public release
- Protects every item that a quest in your quest log asks for
- Yellow "!" on quest items and a padlock on profession tools and items you add yourself, in your bags, Baganator, vendors and the loot window
- Warning and a short button lock when you try to delete a protected item
- Automatic buyback if you sell a protected item by mistake
- Tooltip line that shows why an item is protected
- Options page (`/ql`) with a drop zone to protect any item
